# AutoTrain-Bench episode viewer

Static leaderboard + per-episode agent-trace viewer for AutoTrain-Bench runs
(opencode × GPT-5.6 sol / luna / terra on 4×A100). Generated by
`tools/atb_viz.py --public` from the episode directories; absolute cluster
paths and account names are redacted. Regenerate and push `index.html` to update.
